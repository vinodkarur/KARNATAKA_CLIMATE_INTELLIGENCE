## 2. Detailed Technical & Scientific Boundaries

### 2.1 Raingauge Observational Network Gap for Six Districts
- **Description:** While 25 Karnataka districts possess verified multi-decadal historical rainfall observations from physical IMD manual raingauges (1991–2020), six districts lack continuous dedicated stations in this specific historical dataset:
  1. *Bengaluru Urban*
  2. *Bengaluru Rural*
  3. *Dharwad*
  4. *Gadag*
  5. *Mandya*
  6. *Vijayanagara* (newly bifurcated administrative district)
- **Impact & Handling:** To prevent scientific fraud or data fabrication, the platform explicitly flags these districts with `has_gauge_data: false`, `annual_rainfall_mm: null`, and `data_status: "Data unavailable (No direct IMD manual raingauge station in 1991–2020 dataset)"`.
- **Mitigation:** District-level temperature predictions for these six districts continue to function with high precision using empirical elevation lapse rates. For rainfall, regional downscaled climatological modeling is displayed with clear non-gauge attribution.

### 2.2 Stochastic Nature of Tropical Convective Rainfall ($R^2 \approx 0.23$)
- **Description:** The Gradient Boosting rainfall prediction model achieves a test $R^2 \approx 0.23$ with a Mean Absolute Error of $\approx 4.54\text{ mm}$. In contrast, the temperature model achieves high deterministic accuracy ($R^2 \approx 0.94$, $\text{MAE} \approx 0.73^\circ\text{C}$).
- **Scientific Rationale:** Peninsular Indian rainfall is dominated by mesoscale convective complexes, topography-induced microclimates, and monsoon trough oscillations. Tropical convective precipitation possesses high chaotic variance that cannot be deterministically resolved by daily autoregressive models alone.
- **Operational Boundary:** Rainfall predictions must be interpreted as probabilistic directional indicators of elevated heavy precipitation risk and catchment drainage stress, rather than deterministic pinpoint flash-flood forecasts.

### 2.3 Precipitation-Gauge Statistical Indicator vs. Hydrodynamic Basin Model
- **Description:** Early warning flood alerts are triggered when predicted rainfall exceeds local historical percentile thresholds (P75, P90, P95).
- **Scientific Boundary:** These alerts reflect precipitation-gauge statistical indicators and meteorological drainage stress. They do not incorporate hydrodynamic river basin flow routing, upstream dam reservoir discharges (e.g., KRS, Almatti, Tungabhadra), or urban storm drain bathymetry.
- **Handling:** All alert titles and rationales in `backend/services/risk.py` carry the explicit disclaimer:
  > *"Precipitation-based statistical indicator, not hydrodynamic river basin model."*

### 2.4 Statewide Machine Learning Pipeline with Climatological Downscaling
- **Description:** The platform's predictive core is trained on the comprehensive 44-year statewide meteorological reanalysis (1981–2024, 16,040 daily records) rather than 31 separate, fragmented local district models.
- **Implementation:** District-specific forecasts are downscaled from the statewide model using empirical physical elevation lapse rates ($-1.2^\circ\text{C}$ to $+1.8^\circ\text{C}$ based on mean district elevation relative to the state median) and orographic multipliers.
- **Operational Boundary:** While highly consistent and physically sound, extreme local microclimatic anomalies (e.g., urban heat island hotspots within specific city wards) require fine-grained municipal sensor networks.

### 2.5 Non-Statutory Civil Decision Support
- **Description:** All early warning bulletins, 4x4 risk matrix classifications, and multi-sector adaptation action protocols generated by the system are designed for civil preparedness and municipal operational planning.
- **Operational Boundary:** This platform does not supersede statutory public weather warnings or emergency disaster proclamations issued by the India Meteorological Department (IMD) or the Karnataka State Natural Disaster Monitoring Centre (KSNDMC).

### 2.6 External Live Weather API Dependencies
- **Description:** Live weather ingestion (`/live-climate`) connects to public meteorological endpoints (Open-Meteo, IMD) for real-time observation streaming.
- **Resilience Strategy:** If external network access is blocked, rate-limited, or unavailable, the system automatically falls back to the latest cached observation or the historical climatological normal without breaking the user interface or failing the API contract.

### 2.7 Scikit-Learn Minor Version Deserialization Warnings
- **Description:** During cold model loading, console logs may display non-fatal warnings:
  ```
  InconsistentVersionWarning: Trying to unpickle estimator StandardScaler from version 1.9.0 when using version 1.9.1.
  ```
- **Impact:** These warnings are informational scikit-learn notifications caused by a minor sub-patch difference between model serializing environment (1.9.0) and the repaired runtime environment (1.9.1). Model weights, coefficients, estimators, and mathematical inferences are 100% identical and verified by the test suites.
